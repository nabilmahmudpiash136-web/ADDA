# আড্ডা (Adda)

একটা ছোট Facebook-স্টাইল ওয়েব অ্যাপ — Flask (Python) + SQLite দিয়ে বানানো।
ফিচার: একাউন্ট তৈরি (ফোন নাম্বার/জিমেইল — একটা দিয়ে একটাই একাউন্ট), হোম ফিড
(বন্ধুর পোস্ট আগে আসে), পোস্ট (টেক্সট + ছবি), লাইক, কমেন্ট, স্টোরি (২৪ ঘন্টা),
বন্ধু যোগ করা, প্রোফাইল (ছবি + বায়ো), এবং একজন থেকে আরেকজনকে মেসেজ পাঠানো।

## নিজের কম্পিউটারে চালানো (টেস্ট করার জন্য)

```bash
cd adda_app
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 app.py
```

তারপর ব্রাউজারে যাও: `http://127.0.0.1:5000`

## নিজের ডোমেইনে সত্যিকারের ইন্টারনেটে তোলা (যাতে বন্ধুরা বিশ্বের যেকোনো জায়গা থেকে ব্যবহার করতে পারে)

আমি (Claude) নিজে থেকে সরাসরি ইন্টারনেটে এই অ্যাপ চালিয়ে দিতে পারি না — এটা তোমার
নিজের হোস্টিং একাউন্টে ডেপ্লয় করতে হবে। সবচেয়ে সহজ কয়েকটা পথ:

### সহজ পথ (কোনো সার্ভার ম্যানেজ করা লাগবে না)
- **Render.com** অথবা **Railway.app** — GitHub-এ কোড পুশ করো, ওদের সাইটে
  "New Web App" দিয়ে রিপো কানেক্ট করো। Start command: `gunicorn app:app`
- **PythonAnywhere** — ফ্রি টিয়ারে Flask আপলোড করে চালানো যায়, বাংলাদেশ/
  ভারত থেকেও কাজ করে ভালো।

তারপর তোমার ডোমেইনের DNS-এ ওই হোস্টিং প্রোভাইডারের দেওয়া CNAME/A রেকর্ড বসিয়ে
দিলেই `www.tomardomain.com` থেকে সাইট খুলবে।

### নিজের VPS (DigitalOcean, Hetzner, ইত্যাদি) থাকলে
```bash
pip install -r requirements.txt
gunicorn -w 4 -b 0.0.0.0:8000 app:app
```
এর সামনে **nginx** বসিয়ে ডোমেইন পয়েন্ট করো, আর **Let's Encrypt (certbot)** দিয়ে
ফ্রি HTTPS লাগিয়ে নাও।

## যা এখনই বদলানো দরকার প্রোডাকশনে যাওয়ার আগে
- `app.py`-তে `SECRET_KEY` এখন `"dev-secret-change-me"` — এটা বদলে একটা
  র‍্যান্ডম লম্বা স্ট্রিং বসাও (এনভায়রনমেন্ট ভ্যারিয়েবল `ADDA_SECRET_KEY` দিয়ে দিতে পারো)।
- `debug=True` প্রোডাকশনে বন্ধ করে দিও (`app.py`-এর একদম শেষ লাইনে)।
- এখন SQLite ফাইল (`adda.db`) ব্যবহার হচ্ছে — অল্প মানুষের (কয়েকশো/হাজার) জন্য
  ঠিক আছে, অনেক বড় হলে PostgreSQL-এ সরানো ভালো হবে।

## যা এখন নেই, পরে যোগ করা যাবে
- ফোন নাম্বার/জিমেইল আসলে ভেরিফাই (OTP/লিংক) করা হয় না — শুধু ইউনিক কিনা চেক হয়।
- রিয়েল-টাইম মেসেজ (এখন পেজ রিফ্রেশ করলে নতুন মেসেজ দেখা যায়)।
- নোটিফিকেশন, সার্চ, গ্রুপ, প্রাইভেসি সেটিংস।

```
  static/css/style.css
  static/uploads/     -> আপলোড করা ছবি এখানে জমা হবে
```
